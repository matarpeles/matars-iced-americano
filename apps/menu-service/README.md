# Menu Service 📋

The source of truth for everything we serve at Matar's Iced Americano.

## Overview

Manages:
- Drink catalog (our famous iced americanos!)
- Food items
- Pricing by region
- Seasonal specials
- Nutritional information
- Customization options

## Tech Stack

- **Language:** Node.js 20
- **Framework:** Express
- **Database:** MongoDB

## Quick Start

```bash
cd services/menu-service
npm install
npm run dev
```
