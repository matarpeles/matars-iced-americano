# Barista Portal 👨‍🍳

Staff operations app for Matar's Iced Americano.

## Overview

Features:
- Order queue management
- Order status updates
- Inventory alerts
- Shift management
- Customer lookup

## Tech Stack

- **Language:** TypeScript
- **Framework:** Next.js 14
- **UI:** Tailwind CSS + shadcn/ui
- **State:** Zustand

## Quick Start

```bash
cd services/barista-portal
npm install
npm run dev
```
