# Payment Gateway 💳

Secure payment processing for Matar's Iced Americano.

## Overview

Handles all payment methods:
- Credit/Debit cards (Stripe)
- Apple Pay / Google Pay
- Gift cards & store credit
- Loyalty points redemption

## Tech Stack

- **Language:** Go 1.21
- **Framework:** Gin
- **Security:** PCI-DSS Level 1 compliant

## Quick Start

```bash
cd services/payment-gateway
go mod download
go run src/main.go
```
