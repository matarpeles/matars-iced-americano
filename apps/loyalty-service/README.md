# Loyalty Service ⭐

Customer rewards program for Matar's Iced Americano.

## Overview

Features:
- Points accumulation (1 point per $1)
- Reward tiers (Bronze, Silver, Gold, Platinum)
- Free drink rewards
- Birthday rewards
- Member-only promotions

## Tech Stack

- **Language:** Go 1.21
- **Framework:** Echo
- **Database:** Redis + PostgreSQL

## Quick Start

```bash
cd services/loyalty-service
go mod download
go run src/main.go
```
