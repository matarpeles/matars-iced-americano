# Mobile App Backend 📱

API backend for Matar's Iced Americano mobile apps.

## Overview

**Status: Beta Testing**

Supports:
- iOS app (Swift)
- Android app (Kotlin)
- Order ahead functionality
- Store locator
- Push notifications
- Apple Pay / Google Pay

## Tech Stack

- **Language:** Node.js 20
- **Framework:** Fastify
- **Auth:** Firebase Auth
- **Database:** Firestore

## Quick Start

```bash
cd services/mobile-app-backend
npm install
npm run dev
```
