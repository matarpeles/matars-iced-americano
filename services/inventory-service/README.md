# Inventory Service 📦

Supply chain management for Matar's Iced Americano.

## Overview

Tracks:
- Coffee beans (single origin & blends)
- Milk & alternatives
- Cups, lids, straws
- Syrups & flavorings
- Low stock alerts
- Supplier management

## Tech Stack

- **Language:** Python 3.11
- **Framework:** Flask
- **Database:** PostgreSQL

## Quick Start

```bash
cd services/inventory-service
pip install -r requirements.txt
python src/main.py
```
