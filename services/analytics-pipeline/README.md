# Analytics Pipeline 📊

Business intelligence for Matar's Iced Americano.

## Overview

Processes:
- Real-time sales data
- Customer behavior analytics
- Demand forecasting
- Store performance metrics
- Popular items tracking

## Tech Stack

- **Language:** Python 3.11
- **Processing:** Apache Spark
- **Storage:** BigQuery
- **Orchestration:** Airflow

## Quick Start

```bash
cd services/analytics-pipeline
pip install -r requirements.txt
python src/main.py
```
